# Bibliotecas externas

Este projeto utiliza apenas CDNs gratuitos carregados diretamente em `index.html`:

- **howler.js 2.2.4** (player estéreo com loop/pan)
- **localForage 1.10.0** (IndexedDB + fallback)
- **workbox-window 6.5.4** (registro do service worker)

A pasta `libs/` existe apenas para documentar dependências, mantendo o repositório limpo de pacotes binários.
